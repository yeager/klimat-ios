# Klimat — اردو

**ایپ کا نام**  
Klimat: AC کنٹرول

**ذیلی عنوان**  
کلاؤڈ کے بغیر مقامی کنٹرول

**تشہیری متن**  
مطابقت رکھنے والے Daikin AC کو مقامی Wi-Fi سے براہ راست کنٹرول کریں، انٹرنیٹ کے بغیر بھی۔ براہ راست کنٹرول کے لیے کلاؤڈ اکاؤنٹ ضروری نہیں۔

**تفصیل**  
AC کا کنٹرول آپ کے گھر کے مقامی نیٹ ورک میں رہتا ہے۔ Klimat مطابقت رکھنے والے Daikin Wi-Fi اڈاپٹر سے براہ راست جڑتا ہے۔ انٹرنیٹ بند ہونے پر بھی AC کنٹرول کریں۔ اس براہ راست کنکشن کے لیے مینوفیکچرر کا کلاؤڈ، اکاؤنٹ یا سبسکرپشن درکار نہیں۔

اڈاپٹر کا IP پتہ درج کریں یا Klimat کو اپنے مقامی Wi-Fi نیٹ ورک پر تلاش کرنے دیں۔ موجودہ حالت دیکھیں اور پاور، مطلوبہ درجۂ حرارت، موڈ اور پنکھے کی رفتار تبدیل کریں۔ iPhone اور AC ایک ہی مقامی نیٹ ورک پر ہوں اور اڈاپٹر Daikin کے پرانے مقامی HTTP API کی حمایت کرتا ہو۔

Apple Home میں پہلے سے ترتیب دیے گئے مطابقت رکھنے والے تھرموسٹیٹ اور ہیٹنگ/کولنگ آلات بھی شامل کیے جا سکتے ہیں۔ دستیاب کنٹرول آپ کے آلات پر منحصر ہیں۔

**خصوصیات**
- مطابقت رکھنے والے Daikin اڈاپٹرز کا مقامی Wi-Fi سے براہ راست کنٹرول، انٹرنیٹ کے بغیر بھی
- براہ راست Daikin کنٹرول کے لیے کلاؤڈ کنکشن، اکاؤنٹ یا سبسکرپشن نہیں چاہیے
- موجودہ درجۂ حرارت اور حالت دیکھیں
- مطلوبہ درجۂ حرارت، پاور، موڈ اور پنکھے کی رفتار تبدیل کریں
- Apple Home سے مطابقت رکھنے والے آب و ہوا کے کنٹرول شامل کریں

مطابقت اڈاپٹر کے ماڈل، فرم ویئر اور Apple Home میں دستیاب کنٹرول پر منحصر ہے۔ نیٹ ورک تلاش مطابقت رکھنے والے Daikin اڈاپٹرز ڈھونڈتی ہے، تمام AC یا برانڈز نہیں۔
