# Klimat — 简体中文

**App 名称**  
Klimat 空调控制

**副标题**  
无需联网，本地控制

**推广文本**  
通过本地 Wi-Fi 直接控制兼容的 Daikin 空调，即使没有互联网也能使用。直接控制无需云账户。

**描述**  
空调控制留在家中本地完成。Klimat 可直接连接到本地网络中的兼容 Daikin Wi-Fi 适配器。即使互联网连接中断，也可控制空调。此本地直连功能无需制造商云服务、云账户或订阅。

输入适配器的 IP 地址，或让 Klimat 搜索本地 Wi-Fi 网络。查看当前状态，并调整电源、目标温度、运行模式和风速。iPhone 和空调必须连接到同一个本地网络，且适配器需支持 Daikin 旧版本地 HTTP API。

你也可以添加已在 Apple Home 中配置的兼容温控器和冷热设备。具体可用的控制功能取决于家中的配件。

**功能**
- 通过本地 Wi-Fi 直接控制兼容的 Daikin 适配器，无需互联网
- Daikin 直连控制无需云连接、云账户或订阅
- 查看当前温度和运行状态
- 调整目标温度、电源、模式和风速
- 从 Apple Home 添加兼容的温控设备

兼容性取决于适配器型号、固件以及 Apple Home 配件提供的控制功能。网络搜索可查找兼容的 Daikin 适配器，不代表支持所有空调型号或品牌。
