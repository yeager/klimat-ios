# Klimat — svenska

**Appnamn**  
Klimat: AC-styrning

**Undertitel**  
Styr luftkonditionering lokalt

**Kampanjtext**  
Styr kompatibla Daikin-adaptrar via ditt Wi-Fi utan molnkonto. Lägg till klimatreglage som redan finns i Apple Home.

**Beskrivning**  
Ta kontroll över inomhusklimatet med Klimat.

Klimat ansluter direkt till kompatibla Daikin Wi-Fi-adaptrar på ditt lokala nätverk. Ange adapterns IP-adress för att läsa aktuell status och justera ström, börvärde, driftläge och fläkthastighet. Direktanslutningen kräver inget konto hos tillverkaren.

Du kan också lägga till termostater och värme-/kylreglage som redan har konfigurerats i Apple Home. Vilka reglage som visas beror på tillbehören i ditt hem.

**Funktioner**
- Direkt styrning via Wi-Fi av kompatibla Daikin-adaptrar med äldre HTTP-API
- Läs av aktuell temperatur och driftstatus
- Justera börvärde, ström, driftläge och fläkthastighet
- Hämta klimatreglage som stöds från Apple Home
- Spara anslutningsuppgifter på din iPhone

Kompatibiliteten beror på adaptermodell, firmware och vilka klimatreglage Apple Home-tillbehören erbjuder. Nätverkssökningen hittar enheter som annonserar via Bonjour. Många AC-adaptrar gör inte det, så du kan behöva ange IP-adressen manuellt.

Klimat stöder för närvarande den kompatibla lokala Daikin-adaptern och Apple Home enligt beskrivningen ovan. Molntjänster från andra tillverkare och fler lokala protokoll är ännu inte tillgängliga.
