# Klimat — 한국어

**앱 이름**  
Klimat: 에어컨 제어

**부제**  
인터넷 없이 로컬 제어

**홍보 문구**  
호환되는 Daikin 에어컨을 로컬 Wi-Fi로 직접 제어하세요. 인터넷이 없어도 작동하며 클라우드 계정도 필요하지 않습니다.

**설명**  
에어컨 제어가 집 안의 로컬 네트워크에서 이루어집니다. Klimat은 호환되는 Daikin Wi-Fi 어댑터에 직접 연결합니다. 인터넷 연결이 끊겨도 에어컨을 제어할 수 있습니다. 직접 연결에는 제조업체 클라우드, 계정 또는 구독이 필요하지 않습니다.

어댑터 IP 주소를 입력하거나 Klimat이 로컬 Wi-Fi 네트워크를 검색하도록 하세요. 현재 상태를 확인하고 전원, 목표 온도, 작동 모드, 팬 속도를 조절할 수 있습니다. iPhone과 에어컨은 같은 로컬 네트워크에 연결되어야 하며, 어댑터는 Daikin 구형 로컬 HTTP API를 지원해야 합니다.

Apple Home에 이미 설정한 호환 온도 조절기와 난방/냉방 서비스도 추가할 수 있습니다. 사용할 수 있는 제어 기능은 액세서리에 따라 다릅니다.

**기능**
- 호환되는 Daikin 어댑터를 로컬 Wi-Fi로 직접 제어. 인터넷 불필요
- Daikin 직접 제어에 클라우드 연결, 계정, 구독 불필요
- 현재 온도와 작동 상태 확인
- 목표 온도, 전원, 모드, 팬 속도 조절
- Apple Home에서 호환되는 온도 조절 기기 추가

호환성은 어댑터 모델과 펌웨어, Apple Home에서 제공하는 제어 기능에 따라 달라집니다. 네트워크 검색은 호환되는 Daikin 어댑터를 찾으며 모든 에어컨이나 브랜드를 찾는 것은 아닙니다.

**키워드**  
에어컨,Daikin,로컬 제어,Wi-Fi,온도,HomeKit,클라우드 불필요
