# App Store listing translations

Primary listing: `en-US.md`. Localized storefront copy belongs here by App Store locale. App UI language support is maintained separately in the iOS localization catalog.

Target coverage is English plus these 20 widely used App Store languages, and Swedish:

- Spanish (`es-ES`)
- Simplified Chinese (`zh-Hans`)
- Hindi (`hi`)
- French (`fr-FR`)
- Arabic (`ar-SA`)
- Bengali (`bn`)
- Brazilian Portuguese (`pt-BR`)
- Russian (`ru`)
- Urdu (`ur`)
- Indonesian (`id`)
- German (`de-DE`)
- Japanese (`ja`)
- Marathi (`mr`)
- Telugu (`te`)
- Turkish (`tr`)
- Tamil (`ta`)
- Vietnamese (`vi`)
- Korean (`ko`)
- Italian (`it`)
- Polish (`pl-PL`)
- Swedish (`sv-SE`)

The app UI also supports Persian, for 23 locales total including English; App Store Connect does not offer Persian for this app. Store copy covers English, 20 common languages, and Swedish. Polish is included as a storefront locale supported by App Store Connect.

The current iPhone listing leads with direct control of compatible legacy Daikin local HTTP adapters and Apple Home climate services. It does not advertise Mitsubishi local control yet: the desktop Klimat app has been physically verified with two Mitsubishi MSZ-LN35VG2W units using MAC-577IF-2E, while the iOS Swift adapter still needs a physical iPhone check. MELCloud sign-in and device enumeration have been verified for one account, but AC commands have not; the listing does not advertise MELCloud control. Keep these platform and command-test distinctions explicit when preparing the next storefront revision.

App Store header artwork is available in English (`assets/app-store-header-5244x2950.png`) and Swedish (`assets/app-store-header-sv-5244x2950.png`). Upload state is managed in App Store Connect and should be verified there before release.
