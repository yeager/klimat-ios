# iPhone App Store screenshots

These screenshots were captured from Klimat running in the iPhone 18 Pro simulator at 1206 × 2622 pixels (6.3-inch display class).

- `01-home-empty.png` shows network discovery and optional cloud services.
- `02-local-control.png` shows the local device controls. The displayed Daikin device and readings are sample values seeded only in the simulator for this screenshot; no physical air conditioner was connected.

Both files were uploaded to the English (U.S.) iPhone screenshot set in App Store Connect. The build shown uses Klimat's English interface.


`03-watch-control.png` is a capture from the Apple Watch Series 12 (46 mm) watchOS simulator. It shows the Klimat Watch control screen with sample data loaded by a Debug-only preview launch argument; it is a UI preview and does not demonstrate live AC hardware or Watch Connectivity.
